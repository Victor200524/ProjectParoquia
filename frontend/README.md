# ProjectParoquia — Frontend

Interface web do sistema de gestão da Paróquia São Miguel Arcanjo, feita com Next.js 16 (App Router), React 19 e TypeScript.

Para a visão geral do projeto, as funcionalidades e como rodar o sistema completo (banco + backend + frontend), veja o [README principal](../README.md).

## Rodando só o frontend

O backend precisa estar rodando em `http://localhost:8080`.

```bash
npm install
npm run dev
```

Acesse http://localhost:3000
